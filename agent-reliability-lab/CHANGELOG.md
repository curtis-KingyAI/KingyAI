# Changelog

## 0.1.0 — 2026-09-03

Initial public release of six deterministic Node.js 22 labs covering permission gates, idempotent actions, checkpoint recovery, cost circuit breakers, MCP host security, and hard editorial evaluations.

The release includes source, tests, synthetic fixtures, architecture notes, threat models, runbooks, and generated local evidence. The MCP lab uses an in-memory MCP-shaped fixture transport; it is not an SDK or protocol-conformance test.
