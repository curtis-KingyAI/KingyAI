# Security policy

The Kingy Agent Reliability Lab is an educational, offline, mock-only collection. It is not a production agent framework and must not be connected directly to live credentials, customer data, provider accounts, filesystems, or publishing systems.

Do not open a public issue containing credentials, personal or customer data, production policies, real approval grants, private paths, or exploit payloads. Send sensitive reports through [Kingy's contact route](https://kingy.ai/contact/) with the minimum information required to reproduce the issue.

Each lab includes its own threat model, security note, and explicit non-goals.
